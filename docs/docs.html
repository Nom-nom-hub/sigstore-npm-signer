sigstore-npm-signer Documentation

Usage

Signing a Package

The publish command signs your npm package tarball and updates the package.json with the signature:

# Sign and publish a package using the default tarball path
npx sigstore-npm-signer publish

# Specify a custom tarball path
npx sigstore-npm-signer publish --tarball your-package-1.0.0.tgz

# Specify custom Sigstore service URLs
npx sigstore-npm-signer publish --fulcio-url https://custom-fulcio.example.com --rekor-url https://custom-rekor.example.com

Verifying a Package

The verify command verifies the signature of an npm package:

# Verify a package using the default tarball path
npx sigstore-npm-signer verify

# Specify a custom tarball path
npx sigstore-npm-signer verify --tarball your-package-1.0.0.tgz

# Specify custom Sigstore service URLs
npx sigstore-npm-signer verify --fulcio-url https://custom-fulcio.example.com --rekor-url https://custom-rekor.example.com

Command Line Options

Option Description Default
--tarball Path to the package tarball {name}-{version}.tgz
--fulcio-url URL of the Fulcio service Sigstore default
--rekor-url URL of the Rekor service Sigstore default

Configuration

You can configure sigstore-npm-signer by creating a .signerrc file in your project root:

{
  "allowedPublishers": ["github:username", "email@example.com"],
  "enforceVerification": true,
  "fulcioUrl": "https://fulcio.example.com",
  "rekorUrl": "https://rekor.example.com"
}

Configuration Options

Option Type Description Default
allowedPublishers string[] List of allowed publishers (GitHub usernames or email addresses) []
enforceVerification boolean Whether to enforce signature verification on install true
fulcioUrl string Custom Fulcio URL Sigstore default
rekorUrl string Custom Rekor URL Sigstore default

API Reference

Signing

The signPackage function signs a package tarball:

import { signPackage } from 'sigstore-npm-signer';

// Sign a package
const signature = await signPackage({
  tarballPath: 'your-package-1.0.0.tgz',
  fulcioUrl: 'https://fulcio.example.com', // optional
  rekorUrl: 'https://rekor.example.com'    // optional
});

Parameters

Parameter Type Description Required
tarballPath string Path to the package tarball Yes
fulcioUrl string URL of the Fulcio service No
rekorUrl string URL of the Rekor service No

Returns

Promise<string> - The signature as a string

Attaching Signatures

The attachSignature function attaches a signature to a package.json:

import { attachSignature } from 'sigstore-npm-signer';

// Attach a signature to a package.json
await attachSignature(packageJson, signature);

Parameters

Parameter Type Description Required
packageJson object The package.json object Yes
signature string The signature to attach Yes

Verification

The verifyPackage function verifies a package signature:

import { verifyPackage } from 'sigstore-npm-signer';

// Verify a package
await verifyPackage({
  tarballPath: 'your-package-1.0.0.tgz',
  packageJson: packageJsonObject,
  fulcioUrl: 'https://fulcio.example.com', // optional
  rekorUrl: 'https://rekor.example.com'    // optional
});

Parameters

Parameter Type Description Required
tarballPath string Path to the package tarball Yes
packageJson object The package.json object containing the signature Yes
fulcioUrl string URL of the Fulcio service No
rekorUrl string URL of the Rekor service No

Returns

Promise<void> - Resolves if verification succeeds, rejects if it fails

How It Works

Signing Process

  1. The package tarball is hashed using SHA-256
  2. The hash is signed using Sigstore's keyless signing infrastructure
  3. The signature is attached to the package.json file

The signing process uses Sigstore's OIDC-based keyless signing, which means you don't need to manage any private keys. Instead, Sigstore uses your identity (e.g., GitHub identity) to issue a short-lived certificate that's used for signing.

Verification Process

  1. The package tarball is hashed using SHA-256
  2. The signature from package.json is verified against the hash
  3. The verification uses Sigstore's transparency log to ensure authenticity

The verification process checks that the package was signed by an authorized publisher and that the package hasn't been tampered with since it was signed.

Development

Setup

# Clone the repository
git clone https://github.com/yourusername/sigstore-npm-signer.git
cd sigstore-npm-signer

# Install dependencies
npm install

# Build the project
npm run build

# Run tests
npm test
